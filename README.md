# Théâtre 17 - Site Web

Site web pour Emmanuelle Foltête - Cours de théâtre et d'éloquence autour de La Rochelle.

## 📁 Structure du site

```
/
├── index.html              # Page d'accueil avec carrousel
├── dompierre.html          # Inscriptions Dompierre-sur-Mer
├── la-jarrie.html          # Inscriptions La Jarrie
├── eloquence.html          # Inscriptions Cours d'éloquence
├── contact.html            # Contact & Mentions légales
├── css/
│   └── style.css          # Styles principaux
├── js/
│   └── main.js            # JavaScript (carrousel, menu mobile)
└── img/
    ├── theatre1.png       # Image carrousel 1
    ├── theatre2.png       # Image carrousel 2
    ├── theatre3.png       # Image carrousel 3
    └── eloquence.png      # Image éloquence
```
